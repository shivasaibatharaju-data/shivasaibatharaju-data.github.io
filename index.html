AI Health Vault

Working with healthcare data, I kept seeing how hard it is for patients to read their own records. So I built a place to upload medical PDFs, get a structured summary of each one, and ask questions that are answered only from your own documents.

I designed and built all of it: a FastAPI service that extracts text with PyMuPDF and retrieves the relevant chunks for each question, a data layer on PostgreSQL with private AWS S3 storage, and a Next.js front end. It runs on Vercel and Render. The demo uses synthetic records.
